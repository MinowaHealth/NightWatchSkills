# Sleep Signature Log

Accumulated run-up signatures for **scored** nights only (SKILL principle 1). This file only grows.
Each entry is one tight paragraph along the five axes (see `references/signature-axes.md`). Newest
first. Associations at the bottom are *observed co-occurrences*, never causal claims.

> This is the committed **template**. Copy to `SleepSignatureLog.md` (gitignored in a public repo) and
> let it accumulate your own scored nights. Format shown below — replace with real entries.

## GOOD (scored)

### YYYY-MM-DD → DD · onset ~H:MM · <total in-bed>, <deep> deep, <rem> REM, <n> wakes
Subjective: "<verbatim bedtime note>" — <committed / uncommitted?>; symptoms <y/n>.
Wind-down: HR settled to <range>, stress into <band> across the final hour. Inputs: last food ~<gap>
before onset (<reaction y/n>); <tracked input> <y/n + timing>; <other logged inputs, plain facts>. Onset
<relative to norm>. Quality: **GOOD** — <why, from scored architecture>.

## POORER (scored)

### YYYY-MM-DD → DD · onset ~H:MM · <architecture>
Subjective / wind-down / inputs / onset / quality, same shape as above.

## Excluded (unscored — not signatures)
- **YYYY-MM-DD → DD**: Garmin did not score it; rest inferred. Kept as a health-episode-report, not a
  signature. (Unscored nights never enter this log.)

## Emerging associations (observed co-occurrence only — NOT causal; n = <count> scored)
List run-up features that have tracked outcome across scored nights, and which ones did NOT separate
(shared by good and poorer nights). A real signature is a row that stays consistent as more scored
nights land; a coincidence flips. Revisit only when a feature repeats across several nights in the
same bucket.
