# Examples

The skills emit single-page HTML reports (episode reports and run-up signature
cards) plus a comparison matrix. These are **not committed**, because a rendered
report embeds your personal health data.

To generate your own:

- **Episode report** — ask Claude (with the skills + Minowa MCP connected):
  "make an episode report for last night."
- **Run-up signature** — "figure out the run-up to that scored night."
- **Comparison matrix** — "compare the scored sleep signatures so far."

Each lands as `YYYY-MM-DD_*.html` in your outputs. Store them wherever you keep
personal records — outside this repo, or in a private one.
